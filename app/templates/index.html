Built-in OWASP Top 10 Defenses

Real security controls actively enforced in application logic, not cosmetic placeholders.

Broken Access Control (A01)

Protected endpoints require server-verified sessions. Role-Based Access Control (RBAC) halts privilege escalation and unauthorized admin route access with HTTP 403 Forbidden.

@admin_required Anti-IDOR Profile Bounds

Cryptographic Failures (A02)

Passwords hashed with Werkzeug's memory-hard scrypt algorithm. Never stored in plaintext. Session cookies configured with HttpOnly and SameSite=Lax.

scrypt Hashing HttpOnly Cookies

Injection & SQLi (A03)

Full reliance on SQLAlchemy ORM parameterized queries eliminates string concatenation in SQL execution. Form inputs are strictly validated and normalized.

SQLAlchemy ORM Zero String Concat

Insecure Design & Brute Force (A04)

Adaptive rate limiting on authentication routes (5 attempts/min) throttles brute-force password guessing and automated credential stuffing attacks.

Flask-Limiter HTTP 429 Throttle

Security Misconfiguration (A05)

Automated HTTP security headers injected on all responses (Content-Security-Policy, X-Frame-Options: DENY, X-Content-Type-Options: nosniff). Generic error handlers prevent stack trace leakage.

Strict CSP Anti-Clickjacking

Identification Failures (A07)

Generic authentication error messages prevent username enumeration. Old session IDs are invalidated upon login to defeat Session Fixation attacks.

Session Invalidation Anti-Enumeration

Quick Verification & Local Testing

1. Register an Account

Navigate to Register, create a user with a strong password (at least 8 chars, mixed case, numbers & symbols).

2. Explore Role Access

Standard users can access their dashboard and profile, but cannot access /admin (receives 403 Forbidden).

3. Create Administrator

Run flask create-admin in terminal to initialize a secure administrator and unlock user governance.
